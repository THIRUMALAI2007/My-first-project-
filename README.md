🛠️ Project Title
Machine Mechanism Finder
📖 About the Project
The Machine Mechanism Finder is a simple Python-based project designed to help users understand the working mechanisms of commonly used machines in daily life.
It provides basic information about machines like cars, washing machines, elevators, bicycles, and CNC machines. This project is especially useful for students to learn mechanical concepts in an interactive way.
✨ Features
Displays mechanisms of 5 commonly used machines
User-friendly command-line interface
Simple and easy-to-understand explanations
Beginner-friendly Python project
Expandable (can add more machines)
⚙️ How It Works
The program stores machine data in a dictionary
The user selects a machine from the list
The program fetches details from stored data
It displays:
Machine name
Mechanism
Description
